# fund-cards — ספריית כרטיסי mygemel.net

Version-controlled mirror of Karin's pension-fund card screenshots. The skill checks this folder
(and the Google Drive folder `כרטיסי קרנות פנסיה - mygemel`,
id `1iYdd6Gurp8GYnEio9ZUnZfES6iX3rbIQ`) **before** capturing anything new, so a saved card is
automatically associated with a recommendation.

## Naming convention

```
<חברה>__<מסלול-גיל>__<YYYY-MM>.png
```

Examples:

```
הראל__גילאי-50-ומטה__2026-07.png
מיטב__גילאי-50-ומטה__2026-07.png
מור__כל-הגילאים__2026-07.png
```

- **חברה** — הראל / מיטב / מור / מגדל / אלטשולר / כלל / מנורה / הפניקס …
- **מסלול-גיל** — exactly as it appears on the card (e.g. `גילאי-50-ומטה`).
- **YYYY-MM** — the reporting month; use the same month for both funds in a comparison.

Primary drop point for day-to-day use is the **Google Drive folder** (phone-friendly). Add a
card here only when you want it under version control.
