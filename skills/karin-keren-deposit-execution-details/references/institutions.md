# פרטי הפקדה למוסדות — קובץ מאומת (Karin-maintained)

מקור האמת לפרטי ההפקדה. הסקיל `karin-keren-deposit-execution-details` קורא **רק** מכאן ולעולם לא
ממציא מספרי חשבון או קוד מוסד. כל שורה = מוסד (ובמידת הצורך מוצר ספציפי).

**הוראות מילוי:** מלאי כל שדה מתוך הוראות ההפקדה הרשמיות של המוסד. שדה שלא אומת — השאירי
`— (לאימות)`, והסקיל ידווח עליו כחסר במקום להמציא. עדכני את עמודת **סטטוס** ל-`מאומת` + תאריך.

## עמודות
- **מוסד** — שם המוסד (בית השקעות / חברת ביטוח).
- **סוג** — בית השקעות / חברת ביטוח.
- **מוצר** — אם החשבון שונה לפי מוצר (גמל / השתלמות / פנסיה / פוליסת חיסכון). "כללי" אם אחד לכולם.
- **מוטב** — שם המוטב המדויק לחשבון.
- **בנק / סניף / חשבון** — פרטי החשבון להעברה בנקאית.
- **קוד מוסד (מסב)** — לצורך הרשאה / הוראת תשלום.
- **אסמכתא נדרשת** — מה לציין בהעברה כדי שההפקדה תזוהה (למשל: ת.ז + מס' פוליסה).
- **הערות** — כל דגש (שעות קליטה, טפסים נלווים, אימייל לאישור וכו').
- **סטטוס** — מאומת (תאריך) / לאימות.
