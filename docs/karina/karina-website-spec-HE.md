## 1. סקירת הפרויקט ומטרות

### 1.1 המוצר במשפט
KARINA היא **בובת אימון** בגודל אדם, בגרימור ימי עמיד, המשמשת להרצת תרגילי **"אדם בים" (Man Overboard / MOB)**, חילוץ מהמים והעלאה — עבור צוותי אוניות, חילות ים, משמרות חופים, אסדות קידוח, חברות שייט, נמלים, אקדמיות ימיות, יחידות חיפוש והצלה (SAR) ומצילים.

### 1.2 מטרות עסקיות
| # | מטרה | מדד מרכזי (KPI) |
|---|------|------------------|
| G1 | יצירת לידים איכותיים B2B | בקשות להצעת מחיר / תיאום הדגמה |
| G2 | ביסוס סמכות ואמון (בטיחות, תקינה) | זמן שהייה בעמודי משאבים, הורדות דפי מוצר |
| G3 | תמיכה ברשת המפיצים | פעולות "מצא מפיץ", בקשות שותפים |
| G4 | חינוך השוק (תרגילים, תקנים) | צפיות בסרטונים, קריאת מדריכים |
| G5 | טווח בינלאומי | תנועה אורגנית לפי מדינה, כיסוי שפות |

### 1.3 קהלי יעד (Personas)
- **P1 — קצין בטיחות / HSE** (שילוח, אנרגיה ימית): צריך הוכחת עמידה בתקן, ריאליזם בתרגיל, דפי מפרט.
- **P2 — מנהל צי / רכש**: צריך השוואת דגמים, מסלול תמחור, הזמנה בכמות / הצעת מחיר.
- **P3 — רכז הדרכה** (אקדמיה, SAR, מצילים): צריך פרוטוקולי אימון, סרטונים, עמידות.
- **P4 — מפיץ / משווק**: צריך תוכנית שותפים, שוליים, נכסים שיווקיים.
- **P5 — רוכש בחיל ים / משמר החופים**: צריך מפרטים, חוסן, תמיכה במכרזים.

### 1.4 הגדרת הצלחה
מבקר צריך, תוך ~2 דקות: להבין מהי KARINA, לראות אותה בפעולה (וידאו), לאתר את הדגם הנכון, לוודא עמידה בתקן, ולבצע פעולה ברורה אחת — **בקשת הצעת מחיר** או **מציאת מפיץ**.

מגירת Off‑canvas: ניווט אקורדיון התואם לדסקטופ; מתג שפה + חיפוש למעלה; כפתור דביק "בקשת הצעת מחיר" למטה.

### 4.3 תחתית (4–5 עמודות)
- **מוצר:** Pro, Lite, Cadet, SAR, השוואה, אביזרים
- **פתרונות:** כל 8 התעשיות
- **משאבים:** אימון, וידאו, הורדות, מקרי בוחן, בלוג, שאלות, תקינה, מפרט
- **חברה:** אודות, עיתונות, קריירה, מפיצים, הצטרפות כשותף, צור קשר
- **סרגל שירות:** מתג שפה · ניוזלטר · אייקוני רשתות · משפטי (פרטיות/תנאים/עוגיות/נגישות) · שורת ©.

### 4.4 ניווט משני
- **פירורי לחם (Breadcrumbs)** בכל עמוד שאינו הבית.
- **ניווט עוגן דביק בעמוד** בעמודים ארוכים: טכנולוגיה, מפרט, עמוד מוצר, תקינה.
- **קישורי "הצעד הבא"** בסוף סקשנים (למשל מוצר → תקינה → הצעת מחיר).

## 6. Flow של המשתמש

### 6.1 ראשי — קצין בטיחות → הצעת מחיר
```
Google (חיפוש: "man overboard training manikin SOLAS")
  → דף הבית  או  עמוד נחיתה תעשייתי/תקינה
  → קורא ערכים / צופה בוידאו הדגמה
  → מרכז מוצר → בוחר דגם (או השוואה / "עזרו לי לבחור")
  → עמוד מוצר → בודק מפרט ותקינה → מוריד דף מפרט
  → לוחץ "בקשת הצעת מחיר"
  → טופס הצעה (מוצרים → שימוש → אזור → פרטים)
  → אישור (מספר סימוכין, זמן מענה צפוי)
  → [טיפוח באימייל]
```

### 6.2 גילוי מפיץ → רכישה מקומית
```
בית/מוצר → "מצאו מפיץ"
  → מפת מפיצים → סינון לפי אזור
  → נמצא מפיץ → פנייה למפיץ
      └─ אם אין → "צור קשר" → טופס (מנותב למכירות אזוריות)
```

### 6.3 הצטרפות כשותף
```
תחתית/מפיצים → "הצטרפות כשותף"
  → הצעת ערך + שכבות → טופס הגשה → אישור → [מעקב מכירות]
```

### 6.4 חוקר / מדריך → משאבים
```
בית/משאבים → אימון או וידאו
  → קורא פרוטוקול תרגיל / מנגן וידאו
  → מוריד צ'קליסט (פתוח) או דף מפרט (מוגן → טופס קצר)
  → מטופח ל‑הצעה/הדגמה דרך CTA
```

### 6.5 כלי "עזרו לי לבחור דגם"
```
מרכז מוצר או השוואה → "איזו KARINA מתאימה?"
  → ש1 שימוש (נפח תרגול / ים גועש / מצילים / ילד)
  → ש2 סביבה (ים פתוח / נמל / בריכה)
  → ש3 טיפול (מנוף/מסוק / ידני)
  → כרטיס דגם מומלץ → עמוד מוצר / הצעה
```

### 6.6 יצירת קשר מהירה במובייל
```
כל עמוד → כפתור תחתון דביק "בקשת הצעת מחיר"
  → טופס מקוצר למובייל → אישור
```

### 6.7 החלפת שפה
```
כל עמוד → 🌐 EN|HE → אותו עמוד בשפת היעד (URL עם קידומת שפה) → החלת RTL/LTR
```

**כללי Flow גלובליים:** כל עמוד תוכן מסתיים ב‑CTA‑band; כל טופס מסתיים במסך אישור מפורש; כל "מבוי סתום" (404/אין מפיץ) מציע פעולה הבאה.

## 7. רשימת רכיבי UI

### 7.1 גלובלי / פריסה
- סרגל עליון (הודעה — אופציונלי, ניתן לסגירה)
- Header דביק + תפריט‑על (דסקטופ) / מגירת Off‑canvas (מובייל)
- מתג שפה (EN/HE, ניתן להרחבה)
- חיפוש אתר (Overlay) + רכיב תוצאות
- פירורי לחם
- תת‑ניווט עוגן דביק בעמוד (Scrollspy)
- תחתית (רב‑עמודות) + טופס ניוזלטר + שורת רשתות
- רצועת CTA (רכיב המרה לשימוש חוזר)
- באנר הסכמת עוגיות
- כפתור "חזרה למעלה"

### 7.2 בלוקי תוכן
- Hero (וידאו / תמונה / מפוצל)
- כרטיסי ערך (אייקון + כותרת + טקסט)
- שורת תכונה (תמונה↔טקסט לסירוגין)
- בלוק סטטיסטיקה / מונה
- כרטיס מוצר
- טבלת השוואת דגמים (כותרת דביקה, ערימה במובייל)
- טבלת מפרט (מסוננת, רספונסיבית)
- אריח תעשייה / כרטיס מגזר
- כרטיס מקרה בוחן + פריסת עמוד מקרה
- כרטיס בלוג + פריסת מאמר + ציטוט בולט
- כרטיס משאב (תג סוג: וידאו/PDF/מדריך)
- אקורדיון (שאלות, פרוטוקולי תרגיל)
- לשוניות (Tabs)
- תג / צ'יפ תעודה
- בלוק המלצה / ציטוט
- ציר זמן (סיפור החברה)
- דיאגרמת אנטומיה אינטראקטיבית (נקודות חמות + Tooltips)
- מפת מפיצים אינטראקטיבית + סינון אזור + רשימה

## 10. אסטרטגיית SEO

### 10.1 מטרות
דירוג בינלאומי לשאילתות B2B בכוונת רכישה בתחום הבטיחות הימית; השגת סמכות קטגורית ל‑"man overboard / MOB training manikin"; תמיכה בטווח רב‑לשוני.

### 10.2 נושאי מילות מפתח (זרעים)
- **טרנזקציוני:** "man overboard training manikin", "MOB rescue dummy", "water rescue manikin for sale", "maritime rescue training doll", "SOLAS MOB drill equipment".
- **מגזרי:** "navy man overboard training", "offshore MOB drill manikin", "cruise ship rescue drill dummy", "lifeguard rescue manikin".
- **אינפורמטיבי (בלוג/משאבים):** "how to run a man overboard drill", "SOLAS MOB drill requirements", "MOB recovery techniques", "man overboard procedure checklist".
- **השוואה/מותג:** "KARINA manikin", "[מתחרה] alternative", "best rescue training manikin".

כל עמוד ראשי מחזיק אשכול מילות מפתח **אחד**; הבלוג לוכד long‑tail אינפורמטיבי המזין את המשפך.

### 10.3 SEO On‑page (דרישות לכל עמוד)
- `<title>` ייחודי (≤60 תווים) ו‑meta description (≤155) — לפי תבנית לכל סוג עמוד, מתורגם.
- `<h1>` אחד לעמוד; מבנה H2/H3 לוגי התואם לסקשנים.
- כתובות URL תיאוריות, מודעות למילות מפתח, קריאות (כפי שמשתקף במפת האתר).
- קישור פנימי: Hub‑and‑spoke (מרכזי מוצר/תעשיות/משאבים → ילדים; קישורי הקשר מוצר↔תעשייה↔תקינה↔הצעה).
- טקסט חלופי + שמות קבצים תיאוריים לתמונות; כיתובים במקום שמועיל.
- סימון Breadcrumb בכל העמודים.

### 10.4 SEO טכני
- **בינאום:** כתובות עם קידומת שפה (`/en/…`, `/he/…`), תגי `hreflang` (כולל `x-default`), Sitemap לכל שפה.
- XML Sitemap + `robots.txt`; תגי Canonical נקיים (מפנים לעצמם; Canonical לתצוגות מסוננות/מעומדות).
- מהיר, מותאם Core Web Vitals (ר' §12): LCP < 2.5 ש', INP < 200 מ"ש, CLS < 0.1.
- Mobile‑first, רספונסיבי, ללא Interstitials מטרידים.
- HTTPS, HTTP/2+, דחיסה, פורמטי תמונה מהדור הבא, Lazy‑loading.
- טיפול בעימוד (בלוג) ובסינון פאנלים (מפרט/וידאו) ללא ניפוח אינדקס (Canonical/`noindex` לתצוגות מסוננות לפי הצורך).
- נתונים מובנים (JSON‑LD): `Organization`, `Product` (+ `Offer`/צבירה במקום לגיטימי), `BreadcrumbList`, `FAQPage` (שאלות), `VideoObject` (וידאו), `Article` (בלוג), `LocalBusiness`/נתוני מפיץ במקום רלוונטי.

### 10.5 תוכן וסמכות
- מנוע משאבים/בלוג המכוון לשאילתות אינפורמטיביות (תרגילים, תקנים, טכניקות) → CTA להמרה.
- מקרי בוחן כהוכחה חברתית + לכידת long‑tail.
- PR דיגיטלי / קישורים נכנסים מגופי בטיחות ימית, תקינה, גופי הדרכה, אתרי מפיצים.
- SEO לוידאו (סכמת VideoObject, תמלולים, אסטרטגיית אחסון, נוכחות YouTube אופציונלית המזינה את האתר).

### 10.6 שיקולים מקומיים / בינלאומיים
- נכונות `hreflang` בין EN↔HE (ושפות עתידיות); הימנעות מקנס תוכן כפול באמצעות Canonical + hreflang.
- מילות מפתח מקומיות (לא תרגום מילולי) לכל שוק.
- עמודי מפיצים יכולים ללכוד כוונה אזורית/מקומית.

### 10.7 מדידה
Search Console (לכל שפה), יעדי אנליטיקס ממופים ל‑G1–G5, מעקב אירועים (שליחת הצעה, הורדת מפרט, ניגון וידאו, חיפוש מפיץ), מעקב דירוגים לאשכולות הזרע.

### 10.8 צ'קליסט SEO להשקה
מפת הפניות (אם יש Legacy) · הגשת Sitemap · אימות robots · אימות נתונים מובנים · ביקורת titles/metas/hreflang · מעבר CWV · טיפול 404/500 · אימות אנליטיקס ו‑Search Console לכל שפה.

## 11. לוקליזציה

- **שפות בהשקה:** אנגלית (ברירת מחדל, `x-default`) ועברית (RTL). הארכיטקטורה חייבת לתמוך בהוספת ES/FR/DE/EL/ZH ללא שכתוב.
- **RTL:** מראה מלאה לעברית — כיוון פריסה, ניווט, פירורים, סליידרים, אייקונים בעלי משמעות כיוונית, יישור טפסים; טיפול נכון במספרים/יחידות; מחסנית טיפוגרפיה עם גופנים עבריים איכותיים.
- **מודל תוכן:** לכל עמוד, מחרוזת רכיב, טקסט חלופי, מטא ומסמך (דפי מפרט) יש וריאנט EN ו‑HE; נפילה חזרה ל‑EN אם חסרה מחרוזת.
- **מתג שפה:** שומר בחירה; עובר לעמוד המקביל (לא לבית) היכן שקיים; URL עם קידומת שפה.
- **תרגום:** מקצועי, מותאם שוק (Transcreation לכותרות/CTA, לא מילולי); מילון מונחים עקבי (מונחי ים/בטיחות).
- **פורמטים:** תאריכים, מספרים, טלפון, כתובת מותאמים מקומית; ניתוב פניות לפי אזור.
