## 1. עובדות מוצר ומותג

**מהי:** KARINA היא בובת אימון בגודל אדם (158 ס"מ) בצורת אישה, המתנהגת כמו נפגע אמיתי במים — ראש צף, גוף שוקע, סחיפה וגרירה ריאליסטיות — ופותרת את הכשל המרכזי של מצופי אימון MOB סטנדרטיים.

**מפרט טכני (מהאתר החי):**
| מאפיין | ערך |
|---|---|
| גובה כולל | 158 ס"מ · צורת אישה בגודל טבעי |
| משקל יבש | 70 ק"ג · תואם אישה בוגרת ממוצעת |
| משקל במים | 55–65 ק"ג · ציפה אנטומית מדויקת |
| רוחב כתפיים | 42 ס"מ |
| פרופיל ציפה | ראש צף · גוף שוקע · סחיפה ריאליסטית |
| מבנה | בד עמיד למים · מילוי פנימי · משקולות מכוילות |
| חילוץ | רצועת גרירה משולבת · תואמת לציוד חילוץ סטנדרטי |
| קניין רוחני | **פטנט רשום** · אב‑טיפוס הושלם · מוכן לייצור |

**תכונות מפתח:** התנהגות MOB אמיתית · משקל מכויל · רצועת גרירה מקצועית (מותן+ירך) · מוכנה למים פתוחים (ים/נמל/אגם/בריכה) · ריאליזם ויזואלי (צורה אנטומית) · עמידה ותחזוקה נמוכה.

**מיתוג:** Navy `#0d1b2e`/`#122536` + Gold `#c9a84c`/`#dfc078` + Cream `#f4ede0`. גופנים: **Cormorant Garamond** (כותרות) + **Montserrat** (גוף). טון: יוקרתי, ימי, מינימליסטי — *"Designed for realism. Engineered for safety."* הלוגו כיום הוא **Wordmark טקסטואלי** זהב (אין קובץ לוגו וקטורי).

**עוגן השקה:** **Monaco Yacht Show — ספטמבר 2026** (בכורה בינלאומית).

**מייסדת:** **Karin Keren** — Entrepreneur · Skipper · Inventor (ישראל); מחזיקת פטנט.

## 11. אסטרטגיית SEO

### 11.1 נושאי מילות מפתח
- **טרנזקציוני:** "man overboard training dummy", "MOB rescue mannequin", "maritime rescue training dummy", "man overboard drill equipment".
- **מגזרי:** "coast guard MOB training", "sailing school man overboard drill", "superyacht crew rescue training", "lifeguard rescue mannequin".
- **אינפורמטיבי (משאבים/שאלות):** "how to run a man overboard drill", "man overboard recovery techniques", "MOB drill checklist", "why buoys fail MOB training".
- **מותג/אירוע:** "KARINA rescue mannequin", "KARINA Monaco Yacht Show 2026", "Karin Keren KARINA".

כל עמוד ראשי מחזיק אשכול אחד; המשאבים לוכדים long‑tail אינפורמטיבי המזין את Request Information.

### 11.2 On‑page
Title ייחודי (≤60) + meta description (≤155) לכל עמוד, מתורגם · H1 אחד · מבנה H2/H3 · URLs קריאים (לפי מפת האתר) · קישור פנימי Hub‑and‑spoke · alt + שמות קבצים תיאוריים · סימון Breadcrumb.

### 11.3 טכני
- בינאום: URLs עם קידומת שפה (`/en/`, `/he/`), `hreflang` כולל `x-default`, Sitemap לכל שפה.
- XML Sitemap + robots.txt · Canonical עצמי · Core Web Vitals (LCP<2.5s, INP<200ms, CLS<0.1) · Mobile‑first · HTTPS/HTTP2 · תמונות מהדור הבא · Lazy‑load.
- נתונים מובנים (JSON‑LD): `Organization` (KARINA / Karin Keren), `Product` (הבובה + מאפייני מפרט), `BreadcrumbList`, `FAQPage`, `VideoObject`, `Event` (Monaco Yacht Show 2026), `Person` (Karin Keren).

### 11.4 תוכן וסמכות
משאבים/שאלות סביב שאילתות תרגילי MOB → CTA. Monaco Yacht Show 2026 כוו PR/Event‑SEO (Event schema, עיתונות). סיפור מייסדת ל‑E‑E‑A‑T. קישורים נכנסים מגופי בטיחות ימית, בתי ספר לשיט, ומגזרי אירועים/עיתונות.

### 11.5 מדידה
Search Console לכל שפה · יעדים ל‑G1–G4 · מעקב אירועים (שליחת Request Info, Book Demo, הורדת דף מפרט, קליק וואטסאפ, ניגון וידאו) · מעקב דירוגים.

### 11.6 צ'קליסט השקה
Sitemap · robots · אימות נתונים מובנים (כולל Event) · ביקורת titles/metas/hreflang · CWV · 404/500 · אנליטיקס + Search Console לכל שפה.

- **השקה:** אנגלית (ברירת מחדל, `x-default`) + עברית (RTL). ניתן להרחבה ל‑FR/IT/ES/EL (שווקי מונקו/הים התיכון).
